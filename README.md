# ISN Lab Website

Static website for the Intelligent Systems and Networks Laboratory (ISN Lab) at GIST.

## Files
- `index.html` — home page
- `people.html` — lab members
- `research.html` — research areas
- `publications.html` — publication list
- `news.html` — lab news
- `join.html` — recruiting and contact
- `assets/css/style.css` — shared styling

## GitHub Pages
Upload these files to the root of `sunjungkang3.github.io` and GitHub Pages will serve the site automatically.
